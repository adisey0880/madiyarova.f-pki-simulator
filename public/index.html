Генерация RSA-ключей

Центр сертификации (CA)

Certificate Authority

Центр сертификации (CA) выпускает цифровые сертификаты, связывая открытый ключ с идентичностью владельца. Выберите пользователя и предоставьте открытый ключ для создания сертификата.

Электронная подпись

Digital Signature (RSASSA-PKCS1-v1_5)

Подпишите сообщение с помощью закрытого ключа. Подпись создаётся алгоритмом RSASSA-PKCS1-v1_5 с хешем SHA-256 прямо в браузере.

🖊️ Цифровая подпись (Base64)

Проверка подписи

Signature Verification

Проверьте подлинность подписи с помощью открытого ключа подписавшего. Верификация выполняется в браузере через Web Crypto API.
